# forge/scripts

Automation scripts for platform operations. Not test code — these support the business of running Northform Forge.

## Planned Scripts

| Script | Purpose |
|---|---|
| `onboard-client.sh` | Scaffold a new `clients/client-[slug]/` workspace from templates |
| `generate-report.sh` | Aggregate test results into a GitHub Pages dashboard |
| `validate-structure.sh` | Lint client workspace structure for consistency |
